# Iris Cleaning Service

Web application for managing and booking cleaning services online.

## Description
Iris Cleaning Service is a full-stack web application that allows clients to
request cleaning services and administrators to manage bookings efficiently.

## Features
- Online service booking
- Customer contact form
- Admin management panel
- Responsive design

## Technologies Used
- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB
